本目录已经按 GitHub Pages 的根目录结构整理完成，可直接上传到仓库根目录。

游戏介绍
故事背景
前世，镇北少帅萧决守住雁门关，却因一封伪造的通敌密信被押至午门问斩，萧氏满门倾覆。临刑前，他在人群中看见了自己的宿敌沈砚——那个摄政王世子掷来的断刃，像是给这盘死局留下的一点裂缝。
再睁眼，萧决回到七年前初入京城为质的夜晚。距离萧家覆灭还有整整七年，而构陷的棋局已经开始落子。
这一次，玩家需要决定：
是主动夜访摄政王府，与沈砚结盟？
是连夜出城召集旧部，独自以兵权破局？
还是入宫反间，假意投诚后借刀杀人？
每一次选择都会改变「谋 / 势 / 契」三项数值，进而影响萧决与沈砚的关系、朝堂局势，以及最终能否改写前世命运。
核心玩法
剧情选择：在关键节点做出选择，进入不同分支。
属性影响：选择会改变谋略、势力、羁绊数值。
小游戏挑战：在「朝堂辨伪」等节点完成限时点击挑战。
多结局收集：不同路线和属性组合会触发不同结局，可反复入局收集。
本地存档：支持自动存档与 3 个手动存档位，存档数据保存在当前浏览器中。

## 必须保持的结构

```text
/
├── index.html
├── assets/
│   ├── bgm/
│   └── video/
├── README.md
├── .nojekyll
└── 视频生成提示词归档.md
```

不要将整个发布包再套入一层子文件夹，否则 GitHub Pages 无法在仓库根目录找到 `index.html`。

## 部署

1. 将本目录内的全部文件和文件夹上传到 GitHub 仓库根目录。
2. 打开仓库的 **Settings → Pages**。
3. Source 选择 **Deploy from a branch**。
4. Branch 选择 **main**，目录选择 **/ (root)**，然后保存。
5. 等待 Actions 构建成功后访问：`https://你的用户名.github.io/仓库名/`。
