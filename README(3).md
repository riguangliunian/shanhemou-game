# 山河谋 · 互动漫剧 Demo

《山河谋》是一款 **重生 × 权谋 × 双男主** 题材的单文件 H5 互动漫剧 Demo。玩家将扮演重生归来的镇北少帅 **萧决**，在满门被构陷的前世阴影中重新入局，与摄政王世子 **沈砚** 在猜忌、结盟与反间之间共同揭开伪造密信背后的朝堂杀局。

Demo 已整理为可直接发布到 GitHub Pages 的静态站点：不依赖后端服务，不需要安装构建工具，打开 `index.html` 即可试玩。

## 在线 / 本地效果

- 竖屏互动漫剧体验，适配移动端 9:16 视觉布局
- 5 个章节：序章、重生开局、分支推进、终局落子、多结局收束
- 3 条主分支：结盟线、独行线、反间线
- 5 个结局：共掌山河、孤身问鼎、江湖远遁、重蹈覆辙、玉石俱焚
- 角色属性：谋、势、契会随选择变化，并影响最终结局
- 包含剧情回看、本地存档 / 读档、角色档案、BGM、电影化转场和小游戏节点

## 游戏介绍

### 故事背景

前世，镇北少帅萧决守住雁门关，却因一封伪造的通敌密信被押至午门问斩，萧氏满门倾覆。临刑前，他在人群中看见了自己的宿敌沈砚——那个摄政王世子掷来的断刃，像是给这盘死局留下的一点裂缝。

再睁眼，萧决回到七年前初入京城为质的夜晚。距离萧家覆灭还有整整七年，而构陷的棋局已经开始落子。

这一次，玩家需要决定：

1. 是主动夜访摄政王府，与沈砚结盟？
2. 是连夜出城召集旧部，独自以兵权破局？
3. 还是入宫反间，假意投诚后借刀杀人？

每一次选择都会改变「谋 / 势 / 契」三项数值，进而影响萧决与沈砚的关系、朝堂局势，以及最终能否改写前世命运。

### 核心玩法

- **剧情选择**：在关键节点做出选择，进入不同分支。
- **属性影响**：选择会改变谋略、势力、羁绊数值。
- **小游戏挑战**：在「朝堂辨伪」等节点完成限时点击挑战。
- **多结局收集**：不同路线和属性组合会触发不同结局，可反复入局收集。
- **本地存档**：支持自动存档与 3 个手动存档位，存档数据保存在当前浏览器中。

## 项目结构

```text
/
├── index.html                      # 游戏入口，单文件 H5 主体
├── assets/                         # 游戏运行所需图片、视频、BGM 等素材
│   ├── bgm/                        # 背景音乐与授权说明
│   └── video/                      # 本地视频 fallback 资源

└── 视频生成提示词归档.md            # 视频素材生成提示词归档
```

> 注意：请保持 `index.html` 与 `assets/` 位于仓库根目录。不要把整个项目再套进一层子文件夹，否则 GitHub Pages 可能找不到入口文件。

## 本地部署试玩

### 方式一：直接打开（最快）

适合只想本地试玩：

1. 下载或 clone 本仓库。
2. 进入项目根目录。
3. 双击 `index.html`，或在浏览器中打开该文件。

由于游戏数据、样式与脚本已内联在 `index.html` 中，核心剧情可以直接运行；素材会从 `assets/` 目录读取。

### 方式二：启动本地静态服务（推荐）

部分浏览器对 `file://` 下的音视频加载策略较严格，推荐使用本地 HTTP 服务试玩。

#### 使用 Python

```bash
git clone https://github.com/riguangliunian/shanhemou-game.git
cd shanhemou-game
python3 -m http.server 8000
```

然后在浏览器打开：

```text
http://127.0.0.1:8000/
```

#### 使用 Node.js

如果你本机有 Node.js，也可以使用：

```bash
git clone https://github.com/riguangliunian/shanhemou-game.git
cd shanhemou-game
npx serve .
```

根据终端提示打开本地地址即可。

## 发布到 GitHub Pages

1. 将本仓库内容上传到 GitHub 仓库根目录。
2. 打开仓库的 **Settings → Pages**。
3. Source 选择 **Deploy from a branch**。
4. Branch 选择 `main`，目录选择 `/ (root)`。
5. 保存后等待 GitHub Pages 构建完成。
6. 访问：

```text
https://你的用户名.github.io/shanhemou-game/
```

如果你使用的是自定义仓库名，请把上方 URL 中的 `shanhemou-game` 替换成实际仓库名。

## 运行说明

- 首次进入时点击开始按钮进入游戏。
- 如浏览器阻止自动播放音乐，请点击右上角音频按钮开启 BGM。
- 可通过右侧功能按钮打开「剧情回看」与「存档」。
- 存档保存在当前浏览器的 `localStorage` 中，清理浏览器数据后会丢失。
- 视频资源默认优先使用线上 COS 地址；若不可用，会自动回落到 `assets/video/` 下的本地视频资源或 2.5D 分镜演出。

## 素材与授权说明

- 游戏美术、视频、音频等运行素材均位于 `assets/` 目录。
- BGM 授权与来源说明见 `assets/bgm/CREDITS_AND_LICENSE.md`。
- `视频生成提示词归档.md` 记录了视频素材生成过程中的提示词，便于后续迭代复用。

## 技术说明

本 Demo 是 `interactive-manhua-agent` 项目的最终展示作品之一，用于验证「AI 生成互动漫剧游戏」的可玩形态。当前仓库本身是静态发布包，重点承载最终试玩体验；生成链路、Agent 流水线和可视化工具的详细设计，可参考 interactive-manhua-agent 项目文档。

## 兼容性

推荐使用最新版 Chrome、Edge、Safari 或移动端浏览器访问。若遇到音视频无法播放，优先尝试使用本地静态服务方式运行。
